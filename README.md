# Fashion Product Intelligence

Return-aware merchandising analytics for fashion retail.

## Project goal

This project analyses real anonymised fashion retail transactions
to identify products that appear successful at gross-sales level
but underperform once returns are incorporated.

The project will combine:

- Python
- SQL
- Product & Merchandising Analytics
- Power BI
- Strategy / MicroStrategy
- Semantic Layer / Trusted Metrics
